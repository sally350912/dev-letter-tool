# 房屋銷售：純文字文案與精簡 DM 分流設計

日期：2026-06-30

## 目標

把房屋銷售功能拆成「純文字文案」與「精簡 DM」兩種輸出。文案工具保留完整句型能力；DM 只呈現買方掃一眼就需要的資訊，降低畫面密度。

## 使用流程

1. 使用者進入「房屋銷售」。
2. 填寫同一份物件與業務資料。
3. 選擇輸出分頁：
   - 純文字文案
   - 精簡 DM
4. 純文字文案可使用六類形容詞、四種個人口吻與可編輯文案。
5. 精簡 DM 直接套入必要資訊，不放完整文案。

## 純文字文案

保留現有功能：

- 六類物件形容詞。
- 親切陪伴、專業顧問、活潑有趣、俐落成交四種口吻。
- 主標題、開場、物件賣點與 CTA 四段文案。
- 產生文案、換一版與手動編輯。
- 一鍵複製完整文字。

文案結果獨立顯示，不作為 DM 的長篇內文。

## 精簡 DM 資訊

### 上方物件主卡

- 店家 Logo。
- 固定小標「本月精選物件」；使用者可修改。
- 物件名稱或一句短標題。
- 物件照片一張。
- 3～4 個規格：坪數、房型、樓層、地段。缺少的欄位自動略過。
- 總價，使用高辨識色塊呈現。

### 下方聯絡條

- 固定引導文字「賞屋請找」。
- 業務員姓名與電話。
- QR Code。
- 業務員照片。
- 店址與經紀證號使用小字放在底部。

上方物件主卡與下方聯絡條合成同一張完整 DM，不輸出成兩張圖片。

## DM 尺寸

### A4 橫式

- 297 × 210 mm。
- 適合列印、派報與存 PDF。
- 上方物件區約佔 72%，下方聯絡條約佔 28%。

### 社群 DM

- 採接近參考圖的 4:3 橫式比例，輸出 1200 × 900 px。
- 適合 LINE、Facebook 與社群私訊。
- 與 A4 共用資訊結構，但字級與照片比例獨立調整。

## 字量限制

- DM 主標最多 22 個中文字。
- 物件規格最多 4 項。
- 每項規格最多 14 個中文字。
- DM 不顯示完整開場、賣點段落或長 CTA。
- 聯絡文字最多一行，超出時縮短或截斷，不壓縮其他區塊。

## 視覺方向

- 採「房仲實用型」：白底、黑字、大標、醒目價格。
- 上方照片與文字並排，不在照片上疊長文。
- 下方聯絡條有清楚框線，QR Code 與業務照固定靠右。
- 保留既有四種主題色；主題色只用於價格、圖示與分隔線。
- 網站操作介面維持 Sally 米白、深棕、陶土橘品牌色。

## UI 調整

- 在房屋銷售編輯器加入「純文字文案／精簡 DM」分頁。
- 純文字分頁才顯示形容詞、口吻與四段文案。
- 精簡 DM 分頁顯示 DM 小標、短標題、尺寸選擇與必要資訊提示。
- 預覽區依目前分頁顯示純文字或 DM。
- A4 使用列印／存 PDF；社群 DM 使用下載 PNG。

## 資料與相容性

- 沿用既有物件資料、業務員資料與自動照片壓縮。
- property sales state 新增 outputType 與 dmEyebrow，不覆蓋既有資料。
- Email gate、開發信與成交快報功能維持原狀。

## 驗收標準

- 使用者可以在純文字與精簡 DM 之間切換。
- 四種文案口吻與形容詞選項只影響純文字文案。
- DM 不出現完整開場、賣點段落或長 CTA。
- A4 橫式與 1200 × 900 社群 DM 都包含物件主卡與聯絡條。
- DM 規格最多顯示 4 項，缺值不留下空白項目。
- 價格、電話、QR Code 與業務照片清楚可見。
- 現有照片自動壓縮、資料保存、四種主題色與既有模式不退化。
- 自動檢查涵蓋字量限制、規格數量、兩種 DM builder 與既有功能保留。

## 不納入本次

- 多張物件照片輪播。
- 自動去背或 AI 修圖。
- 多物件批次 DM。
- AI API 文案生成。
