# 房屋銷售模板與句型文案寫手設計規格

日期：2026-06-30

## 目標

新增「房屋銷售」模式，讓房仲勾選物件特色與個人口吻後，快速產生可編輯的銷售文案，並輸出 A4 橫式列印版與 16:9 社群分享版。

第一階段只套用於房屋銷售模式；穩定後再評估延伸到開發信與成交快報。

## 使用流程

1. 使用者完成既有 Email 解鎖。
2. 在用途選擇新增「房屋銷售」。
3. 填寫物件基本資料與上傳主照片。
4. 從六類物件特色中勾選形容詞標籤，可另填自訂特色。
5. 選擇四種個人特質口吻之一。
6. 系統用模組化句型產生標題、開場、賣點描述與 CTA。
7. 使用者可直接編輯生成後的文案。
8. 切換 A4 橫式或 16:9 社群版預覽，列印、存 PDF 或輸出圖片。

## 物件資料

必要欄位：

- 物件標題
- 地址或生活圈
- 總價
- 坪數
- 房型
- 主照片

選填欄位：

- 樓層
- 屋齡
- 車位
- 管理費
- 物件編號
- 其他補充

沿用既有業務員姓名、店名、電話、LINE、Logo、大頭照、自訂 QR Code 與經紀證號。

## 物件形容詞庫

六類標籤：

1. 採光：明亮採光、雙面採光、自然通風、日照充足、室內通透。
2. 格局：格局方正、動線順暢、空間好規劃、房間皆有窗、收納充足。
3. 地段：核心地段、靜巷住宅、交通便利、近捷運、通勤省時。
4. 生活機能：採買方便、學區完整、近公園、餐飲選擇多、日常機能齊全。
5. 景觀：高樓視野、棟距舒適、綠意景觀、城市景觀、永久棟距。
6. 屋況：屋況良好、精緻裝潢、可直接入住、全新整理、保養用心。

每類可複選；整體建議選 3～6 個。另提供自訂特色文字欄位，避免句庫限制真實物件差異。

## 個人特質口吻

### 親切陪伴型

語氣溫暖、生活化，強調入住感受與日常畫面。CTA 以邀請看屋、一起確認需求為主。

### 專業顧問型

語氣穩定、資訊清楚，優先呈現條件、區位與適合的購屋族群。CTA 以安排賞屋與取得完整資料為主。

### 活潑有趣型

句子較短，使用輕鬆比喻與節奏感，但不浮誇、不捏造稀缺性。CTA 可帶一點俏皮感。

### 俐落成交型

直接列出核心賣點、價格與行動方式，減少鋪陳。CTA 強調立即聯繫與預約。

## 句型引擎

採模組化規則，不使用 AI API。輸入相同時仍可切換句型版本，避免所有物件出現完全一致的文案。

輸出由四段組成：

1. 標題：口吻前綴＋地段／房型＋最重要特色。
2. 開場：依口吻描述適合的生活情境或購屋需求。
3. 賣點：把已勾選標籤按採光、格局、地段、機能、景觀、屋況排序並組句。
4. CTA：搭配業務員姓名、電話與 LINE，引導預約賞屋。

所有輸出皆可編輯；使用者重新生成前，若現有文案已修改，要先提示確認，避免覆蓋內容。

## 兩種輸出版型

### A4 橫式

- 尺寸 297 × 210 mm。
- 適合店頭展示、派報、列印與存 PDF。
- 主照片約佔左側 55%，右側放標題、價格、規格、3～5 個特色與 CTA。
- 保留店家 Logo、業務員資訊、QR Code 與經紀證號。

### 16:9 社群版

- 畫布比例 1600 × 900。
- 適合 Facebook、LINE 與簡報式分享。
- 文字量比 A4 少，只保留標題、價格、三項核心特色與聯絡 CTA。
- 使用與 A4 相同資料，但有獨立排版，不直接縮放 A4。

## 視覺原則

- 網站操作介面沿用 Sally 米白、深棕、陶土橘品牌色。
- 房屋銷售成品提供既有四種樣板主題色：深藍、新綠、正紅、金黃。
- 不改動既有開發信與成交快報樣板。
- 功能圖示採一致的線性 SVG；觸控區至少 44 × 44 px。

## 資料與隱私

- 全部句型運算在瀏覽器內完成。
- 物件資料與圖片只存於瀏覽器，不送往 Apps Script 或第三方服務。
- 沿用既有 localStorage，新增獨立 property sales state，避免覆蓋現有資料。

## 錯誤與空狀態

- 缺少必要欄位時，在欄位附近顯示明確提示，不直接開啟列印。
- 尚未勾選特色時，提供「先選 3 個最有感的特色」引導。
- 圖片過大時沿用現有壓縮與大小限制；處理失敗時保留其他欄位內容。
- 重新生成會覆蓋已編輯文案時，必須先詢問使用者。

## 驗收標準

- Email gate、開發信與成交快報功能維持原狀。
- 房屋銷售模式可完成資料輸入、特色複選、口吻切換、文案生成與手動編輯。
- 四種口吻產出的標題、開場、賣點與 CTA 有明顯差異。
- A4 橫式與 16:9 皆使用同一份資料，版面各自適配。
- 四種主題色在兩種尺寸中均可切換。
- 375px、768px、1440px 寬度可操作，無水平捲動。
- 列印、存 PDF 與社群圖片輸出不影響既有輸出功能。
- 自動檢查涵蓋句型組合、必要欄位、版型存在與既有功能保留。

## 不納入第一階段

- AI API 文案生成。
- 雲端儲存物件資料。
- 多物件批次製作。
- 自動抓取房仲平台物件資料。
- 將句型寫手套用到開發信或成交快報。
